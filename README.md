# MacParakeet upstream PR illustrations

Approved screenshots for moona3k/macparakeet PRs #955–#961. These are actual
captures of the corrected integrated app at `fd6c323a`, using fictional meetings,
transcripts, notes, speakers and saved results. The Discover comparison uses two
actual builds of that code, with the feature included or excluded at compile time.
Navigation in this integrated preview may differ from independent feature branches.

The author approved these twelve screenshots and captions before publication.
They illustrate the interface; validation evidence belongs in each PR description.
This separate asset branch keeps binary illustrations out of the code proposals.

`manifest.json` maps each approved image and caption to its PR.
